## The image

`entry.png` (1024×1024, PNG) is a newspaper front page rendered from
`design.html` with a headless browser, so every word is crisp text, never
AI-drawn lettering. Bigger type and shorter decks than the 18 November
entry, so it stays legible at about 300 pixels across:

- **Lead:** Grand Theft Auto VI launches worldwide after 13 years.
- **Kerch Bridge:** hit a third time this week, traffic halted again.
- **Shenzhen:** Trump, Xi and Putin hold their first three-way talks.
- **U.S. Speaker:** Democrats nominate Jeffries.
- **Anthropic:** raises $81.3bn in the biggest IPO ever.
- **Also:** U.S.–Iran fire for a third day, Voyager 1 passes one light-day,
  EU proposes a €45bn Ukraine loan, four nations urge aid access for
  flooded Gaza.

Sources: Reuters, Associated Press, CNN, BBC, Al Jazeera.

## The program

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`/output/entry.png`. It runs twice in the grader and writes identical bytes
both times.
